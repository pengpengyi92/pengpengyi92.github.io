我把下一阶段的关键入口称为“船票”。

它不只是一个 title，而是一个可以兑现的研究入口：

```text
船票 = position + cash flow + research output probability + long-term narrative
```

对我来说，RA 是非常好的船票，但不是唯一船票。

## RA 的价值

一个高质量 RA position 可以提供：

- 真实研究环境
- PI / lab 背书
- 论文或 technical report 机会
- PhD application signal
- 研究讨论密度
- 更接近 AI scientist 的日常工作方式

但 RA 也要筛选。不是所有 RA 都值得替换当前现金流和组织身份。

## 触发离职的条件

7-8 月不是必须离职的时间点，而是一个迁移窗口。

更准确的标准是：

```text
如果高质量船票出现，就执行迁移。
如果没有，就保留当前现金流和 credit，继续申请。
```

一个 RA 足够强，至少要满足其中几项：

- 研究方向贴合 AI agents / quant research / AI for finance。
- 有明确 paper、technical report 或 benchmark 机会。
- 导师或博士后愿意具体指导。
- 能增强下一轮 PhD application。
- 工资、remote、时间自由度可以支撑长期输出。
- 组内环境健康，讨论密度高，成长概率高。

## RA 的替代选项

如果拿不到 RA，仍然有其他船票：

| Option | Value |
|---|---|
| Research Engineer in AI Lab | 工程强、研究近、可能有 paper |
| Quant Researcher / Quant Research Engineer | 主线高度相关、现金流强 |
| AI for Finance Research Engineer | 金融业务和 AI 系统连接强 |
| Funded MPhil / research master | 身份稳定、PhD 路线直接 |
| Remote AI Engineer + Open-source Research | 自由度高，但需要更强自驱 |

核心公式不变：

```text
好船票 =
更靠近 AI Scientist 主线
+ 能产生公开研究资产
+ 不切断现金流
+ 能增强明年 PhD / RA / research role 叙事
```

## 当前执行方式

这个阶段最重要的是 pipeline：

```text
PI / lab list
  -> customized email
  -> one-page CV
  -> GitHub profile
  -> project README
  -> technical note
  -> meeting
  -> offer / collaboration
```

网站和博客的作用，就是把这些材料集中成一个公开可信的入口。

最终目标不是离开某个地方，而是进入更强的研究系统。
